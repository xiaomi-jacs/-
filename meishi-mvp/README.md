# 梅事 MVP

这是一个无需安装依赖、可直接打开的静态网页原型。

## 打开方式

双击 `index.html` 即可体验完整流程：

1. 写下问题并确认提示
2. 凭直觉选择九位数字
3. 查看本卦、互卦、变卦、六爻、体用关系与结构化解读
4. 继续追问或将结果保存到本机签匣

也可以在本目录启动任意静态服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## MVP 说明

- 起卦计算在浏览器本地完成，采用 PRD 中的九位数字规则。
- 第一组三位数计算上卦，第二组计算下卦，第三组计算动爻。
- 互卦、变卦、体用关系均由程序确定性计算。
- 当前解读为本地规则化演示文本，后续可将已确定的卦象结构传给大模型 API，不允许模型重新起卦。
- 历史签保存在浏览器 `localStorage`，最多保留 20 条。
